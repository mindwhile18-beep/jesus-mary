# Infant Jesus English Medium High School Website

A modern, responsive, and visually engaging landing website built for **Infant Jesus English Medium High School** located in Vinjamur, AP (managed by *Joseph's Foundation Charitable Trust*).

## Project Features
- **Aesthetic Design**: Sleek glassmorphism navigation, premium typography, custom color palette matching the school seal, and interactive scroll reveals.
- **Dynamic Stats Bar**: Animated numerical increments when stats come into viewport.
- **Interactive Gallery**: Fully keyboard-accessible Lightbox gallery with previous/next controls.
- **Inquiry Form**: Validates user inputs with responsive success alerts.
- **Embedded Location**: Integrated Google Maps showing Vinjamur, AP.
- **Zero-Dependency Native Server**: Built-in HTTP server requiring no npm dependencies.

## Get Started

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.

### Running the Server
Since this setup runs on a built-in Node server, you do **not** need to install external packages. Start the server directly:

```bash
npm start
```

Once running, navigate to:
👉 **[http://localhost:3000](http://localhost:3000)**
